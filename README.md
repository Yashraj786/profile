# Yash Ramteke - Personal Profile Website

A modern, responsive personal profile website showcasing skills, experience, and contact information.

## Features

### Content Sections
- **Profile Header**: Professional introduction with profile picture
- **Skills & Technologies**: Interactive grid displaying technical skills
- **About Me**: Detailed biography and professional goals
- **Contact Section**: Direct WhatsApp integration
- **Social Links**: Connect via multiple social platforms

### Interactive Features
- **Smooth Scrolling**: Seamless navigation experience
- **Scroll-to-Top Button**: Easy navigation back to top of page
- **Fade-in Animations**: Cards fade in as you scroll down
- **Hover Effects**: Interactive elements with smooth transitions
- **Responsive Design**: Optimized for all device sizes

### Technical Enhancements
- **SEO Optimized**: Meta tags for better search engine visibility
- **Open Graph Tags**: Enhanced social media sharing
- **Accessibility**: ARIA labels and keyboard navigation support
- **Performance**: Lightweight with minimal dependencies

## Technologies Used

- HTML5
- CSS3 (with Flexbox and Grid)
- JavaScript (ES6+)
- Font Awesome Icons

## Customization

### Changing Colors
The primary color scheme uses:
- Primary: `#667eea` (Purple-blue)
- Secondary: `#764ba2` (Deep purple)
- Accent: `#25D366` (WhatsApp green)

### Adding New Skills
Edit the skills grid in `index.html`:
```html
<div class="skill-item">
  <i class="fas fa-your-icon"></i>
  <span>Your Skill</span>
</div>
```

### Modifying Animations
Adjust timing in `style.css`:
```css
transition: all 0.3s ease;
```
